This website is about Susan Kare, a graphic designer known for creating many of the original Apple Macintosh icons and graphics. The website uses a 1980s Macintosh and pixel-art style, with retro computer windows, pixel graphics, animations, and a biography of Susan Kare.

The design includes pixel art throughout the website to connect to Susan Kare's original work, black-and-white colors to represent the original Macintosh screen, Macintosh-style windows to create an old computer appearance, pixel icons to represent early computer graphics, retro fonts for headings and menus, and animations to make the website feel more alive.

The website is also designed for mobile devices. Sections resize to fit smaller screens, navigation and text become smaller, and images and text stack vertically to make everything easier to read on phones.

ChatGPT was used to help brainstorm website ideas, write and improve HTML and CSS, create Macintosh-style designs, add pixel animations, and fix code. AI suggestions were reviewed and changed to fit the project. For example, ChatGPT helped plan the website, create the Macintosh desktop and startup screen, and add animations throughout the page. These suggestions were customized and used in the final website.

Canva was used to plan the desktop and mobile wireframes. ChatGPT was used for brainstorming, coding help, and design ideas. Research sources were used to learn about Susan Kare, her career, and her artwork. Images are credited to their original creators or sources.

After testing the website, I noticed that the bottom sections did not have enough animations. I added more pixel-style animations to the Philosophy, Sources, Design Annotation, and Footer sections. This made the website feel more complete and consistent from beginning to end.

The project contains four main files: `index.html`, which contains the website's content and structure; `style.css`, which controls the design, layout, colors, and animations; `app.js`, which controls the startup screen and simple interactive features; and `README.md`, which explains the project.

The GitHub repository contains the project files and tracks the website's progress.
